## Session Arc Summary

**Opening beat (msgs 1-4):** User learns Tracey's in trouble, phone in evidence.

**Explanation (msgs 5-16):** Tracey lays out the Tesco self-scan disaster, voice notes add authenticity, Hermes bag detail, guard knocked unconscious.

**Dave interrupt (msgs 17-26):** Dave barges in with escalation. Tracey misunderstands PTSD as STI, perfect character moment. Gold comedy line lands.

**Escalation (msgs 27-33):** Vague "spoke to someone," solicitor mention, Tracey spirals to prison. User is now invested in outcome.

**Cliffhanger (msgs 34-36):** Lock screen notification hours later. Tracey's midnight panic about witnesses. User opens app next day wondering what happened.

---

## Notes for Production

- **Voice notes:** Both under 15s, authentic panic/defensive tone. Badly whispered, paused, real. Not polished.
- **Photos:** Tesco selfie should be genuinely blurry with finger in shot. Hermes bag photo shows blood stain (fake, but believable). Both feel caught-in-the-moment.
- **User choices:** All three options are flavour. Tracey's next message is identical regardless which the user taps. This simplifies the script and keeps focus on entertainment, not branching narrative.
- **Timing:** Messages arrive naturally spaced. The 3+ hour gap before lock screen notification creates realism (she was in actual trouble, now panicking at night).
- **Dave's thread:** Separate conversation, uninvited. He's not helpful, just escalating. This is his character.
- **Cliffhanger:** Pulls to Day 2 episode (arrest? solicitor letter? mum finds out?).
